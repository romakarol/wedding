# Our Wedding

A static wedding website built with HTML and CSS. There is no build step or package installation required.

## Run locally

From the project directory, start Python's built-in web server:

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000> in your browser. Press `Ctrl+C` in the terminal to stop the server.

## Pages

- `index.html` — Home
- `venue.html` — Venue
- `accommodation.html` — Accommodation
- `transport.html` — Transport
- `schedule.html` — Schedule
- `party.html` — The Party
- `faq.html` — FAQ
- `gallery.html` — Gallery

Styles are in `css/style.css`, and site images are in `images/`.
